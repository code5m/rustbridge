## 已完成并进入 main 的能力

### 项目与文件

- 能打开真实 `.rs` 文件和真实目录，识别 Cargo 项目根目录。
- 项目树来自真实文件系统；默认排除 `.git`、`target`、`node_modules`，可切换查看排除目录。
- 文件搜索在后台执行，限制搜索深度和结果数，较新的请求会淘汰旧请求。
- 支持最近打开的 Rust 文件（当前为运行期状态）。

### Rust 编辑与安全保存

- 支持语法高亮、行号、查找、基础编辑、保存和常用编辑器快捷键。
- 保存前比较磁盘内容与上次保存内容，检测外部修改或删除，避免无提示覆盖。
- 外部修改有可见提示；干净文件可以重新加载，未保存文件会进入保存/放弃/取消流程。
- 行号、CRLF、尾部换行、Unicode 文本均有单元测试覆盖。

### Java 阅读投影与定位

- Java 视图是只读、近似的学习投影，真实 Rust 文件始终是事实来源。
- 已有 struct、trait、enum、impl、函数、字段、类型、引用表达式和 `move` 闭包等概念锚点。
- Rust 与 Java 投影使用真实 AST 出现的精确字节范围；支持同一行多个符号和 UTF-8 边界。
- 对未知宏、复杂泛型、生命周期、所有权等不能可靠解释的内容保留 Rust 原文，不猜测。
- 支持 Rust、Java、双栏联动和课程视图之间的定位与返回。

### 后台任务与 rust-analyzer

- 投影在后台 worker 中执行，采用 200ms 防抖和 revision 丢弃旧结果。
- 文件搜索独立后台 worker，支持关闭时释放线程。
- rust-analyzer 为可选能力：当前通过命令行诊断执行，支持取消，持续读取 stdout/stderr，并在错误路径清理子进程和读取线程。
- 当前没有完整 LSP 会话、补全或定义跳转。

## 性能基线（探索性，不能当作完整 GUI 验收）

测试记录见 [`docs/performance-baseline.md`](performance-baseline.md)。记录机器为 Linux `7.0.0-38-generic`、AMD Ryzen 7 5700U、8 核 16 线程、14 GiB 内存、4 GiB swap。

已记录的项目规模包括：

- 小项目：`examples/basics.rs`
- 中型 Rust 文件：`zlib-rs`，102,440 bytes、2,734 行
- 大型 Rust 文件：`glow`，1,546,756 bytes、37,802 行

当前记录的 release 二进制约 10,061,456 bytes；独立进程空闲采样为单核 CPU 0.00%，RSS 两端均约 95,304 KiB。采样方法是启动后预热 1 秒，再以 `/proc` 每隔 5 秒采样一次。

这些结果只覆盖进程级空闲样本和命令行诊断。启动时间、真实 GUI 打开文件延迟、连续编辑 CPU/RSS、频繁切换、长时间运行资源释放和可重复的优化前后对比仍未完成，不能虚报为已达标。

## 剩余工作（按优先级）

### P0：真实 Linux 原生 GUI 验收

需要后续 Agent 或人工在 Linux 桌面上实际操作：

1. 打开真实小型、中型 Rust/Cargo 项目。
2. 编辑、撤销/重做、保存，并验证外部修改冲突和关闭提示。
3. 切换 Rust、Java、双栏和课程视图。
4. 从 Rust/Java 锚点双向跳转，验证同一行多个 token、中文/UTF-8、CRLF 和大文件。
5. 从代码知识点进入课程，再返回原位置。

当前 CUA 无法可靠观察该 native window，因此本节点不能宣称 GUI 交互验收已完成。

### P0：可重复的性能与资源测试

补齐测试方法、重复次数和结果：启动耗时、打开文件耗时、编辑响应、投影延迟、搜索延迟、空闲/活动 CPU、RSS、打开文件数、切换项目、关闭项目和长时间运行。至少覆盖小、中、大项目，并记录优化前后同一 workload 的数据。

### P1：增量解析与任务取消

当前 worker 采用防抖和最新 revision 丢弃结果，但单次解析仍可能是整文件重算，正在执行的解析不能主动取消。下一步应评估 Tree-sitter 增量编辑、可见区域渲染和过期任务取消，先以测试证明正确性再优化。

### P1：rust-analyzer 能力边界

如继续接入，优先做可选、可关闭的诊断/补全/定义跳转，并明确区分 AST 映射与真实类型解析。未安装、启动失败或关闭时，阅读和编辑核心流程必须保持可用。

### P1：项目索引与编辑体验

- 目录树仍有同步的按需扫描路径，需要在大目录上实测并视结果迁移到后台索引。

- 需要在真实 GUI 上补证撤销/重做、快捷键、查找连续操作和大文件滚动。
